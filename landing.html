三步，从一堆数字到一句话结论

不要求你换工具、不要求你授权 Amazon 账号、不要求你把数据交给我们。

1

导入你自己的表

CSV / TSV 都行。Keepa 导出的宽表、卖家精灵导出的表、或者你自己拉的 Excel 导出 —— 自动识别列名，并把没识别到的列明确列给你看，不假装全都读懂了。

2

每个品出一张三态结论

GO 有保留 NO-GO，以及第四种我们坚持要有的状态：信息不足。字段不够时我们拒绝下结论，而不是给你编一个看起来精确的分数。

3

拿走推理链和风险清单

每个结论都摊开说明：哪几条证据支持、哪几条反对、最可能亏在哪。报告可导出 Markdown / CSV，数据是你的，随时带走。

常见问题

我的数据会被上传到你们服务器吗？

不必。报告由本地脚本生成，原始文件不需要上传——这也是我们不需要你授权 Amazon 账号的原因。
如果你选「帮你跑一份」，那是你主动把表发给我们，我们只用于生成这一份报告、不做他用，你也可以在收到报告后要求我们删除。

你们的销量数字准吗？

我们不生产销量数据 —— 我们用的是你自己导入的数字，所以准确度取决于你的数据源本身。我们能做的是：明确标出哪些是原始数据、哪些是推算、哪些是缺失。行业里所有工具的销量都是估算值（有卖家实测过，稳定期误差约 15%，做促销时更差），真正的问题是厂商不告诉你这件事。

为什么不直接接 Keepa API 自动取数？

正在评估。技术不是问题，需要先确认 Keepa 的条款是否允许把它的数据对外展示给第三方。在确认之前，我们选择让你导入自己已有的数据 —— 这样你既不用多付一份数据费，我们也不会把你置于条款风险里。

「信息不足」是什么意思？是不是你们功能不全？

是刻意的。如果你只给了一张没有 BSR、也没有价格的表，任何负责任的工具都不该给你一个「GO」。宁可告诉你「缺这两个字段所以我不判断」，也不给你一个精确的错数 —— 后者正是你现在用的工具的毛病。

能处理多少个 ASIN？

免费档单次报告建议 20 个以内；Pro 档支持整份类目列表（数百到数千行）。
