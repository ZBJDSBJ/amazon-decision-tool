# amazon-decision-tool

## 项目简介

amazon-decision-tool 是一个静态HTML网站，已部署到 Vercel。

## 访问地址

- Vercel 部署地址：https://amazon-decision-tool-xxx.vercel.app
- GitHub 仓库：https://github.com/ZBJDSBJ/amazon-decision-tool

## 项目结构

```
amazon-decision-tool/
├── landing.html    # 主页面
├── index.html            # 入口重定向
├── vercel.json           # Vercel 部署配置
├── .gitignore            # Git 忽略规则
└── README.md             # 项目说明（本文件）
```

## 本地开发

直接在浏览器中打开 `landing.html` 即可预览。
